_________________________________________________________________________

 $ chewkeanho-netcontrol lock [FILENAME]
_________________________________________________________________________

LOCK COMMAND

This command locks the 'etc/' configuration directory into an encrypted
archived file for safe storage and data at rest.

It prioritizes full safety-check at each step ensuring the locked encrypted
file is guarenteed unlockable.

The '[FILENAME]' **MUST NOT** have any file extension. Example:
	* 'network-data' -> 'network-data.tar.xz.enc'




WHEN TO USE

**ALWAYS** keep your enterprise network configuration directory in lock-mode
after use. A network is the nerve system of the enterprise. Therefore, always
keep it safe.




LOCKING PIPELINES

This command uses known and common technologies to lock the directory:

(1)	Archive the entire directory into a `tar` archive file with `tar`
	program.
(2)	Verify and test the `tar`-archived file.
(3)	Compress the `tar`-archived file with `xz` program.
(4)	Verify and test the `xz`-compressed file.
(5)	Remove the no longer needed `tar`-archived file.
(6)	Request passphrase from user with **STRICT** policy (refer next
	section).
(7)	Encrypt the `xz`-compressed file with `openssl` program.
(8)	Obtain shasum of the `xz`-compressed file with `openssl` program.
(9)	Mock decrypt a copy of the encrypted file with `openssl` program.
(10)	Obtain shasum of the decrypted `xz`-compressed file with `openssl`
	program.
(11)	Compare both shasum to be identical.
(12)	Clean up all artifacts.
(13)	Remove the configuration directory.
(14)	Inform user the location of the encrypted locked file.




CRYPTOGRAPHY POLICIES

Use the following command to read the program's cryptography policies:

	$ chewkeanho-netcontrol help cryptography
