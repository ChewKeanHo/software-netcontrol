_________________________________________________________________________

 $ chewkeanho-netcontrol unlock [FILENAME]
_________________________________________________________________________

UNLOCK COMMAND

This command unlocks an encrypted archived file from safe storage into
'etc/' configuration directory for use.

It prioritizes full safety-check at each step ensuring the unlocked
payload is expected as it is.

The '[FILENAME]' **MUST HAVE** '.tar.xz.enc' file extension. Example:
	* 'network-data.tar.xz.enc' -> 'network-data.tar.xz.enc'




WHEN TO USE

**ONLY** unlock when you need to use. Lock them back immediately once you
completed everything. A network is the nerve system of the enterprise.
Therefore, always keep it safe.




UNLOCKING PIPELINES

This command uses known and common technologies to unlock the encrypted
locked file:

(1)	Request passphrase from user with **STRICT** policy (refer next
	section).
(2)	Verify and test the `xz`-compressed file with `xz` program.
(3)	Decompress the `xz`-compressed file with `xz` program.
(4)	Verify and test the `tar`-archived file with `tar` program.
(5)	Remove the no longer needed `xz`-compressed file.
(6)	Unarchive the `tar`-archived file back into the entire directory.
(7)	Remove the no longer needed `tar`-archived file.
(8)	Remove the encrypted locked file.
(9)	Clean up all artifacts.
(10)	Inform user the location of the encrypted locked file.




CRYPTOGRAPHY POLICIES

Use the following command to read the program's cryptography policies:

	$ chewkeanho-netcontrol help cryptography
