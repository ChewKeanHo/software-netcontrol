STUBBY PACKAGE

Stubby is a simple DNS-over-TLS (DoT) stub resolver commonly used across
UNIX-like platforms. The goal here is to protect all DNS queries from
Man-in-the-Middle (MitM) attacks (e.g. by an Internet Service Provider or
by other malicious entities).

In OpenWRT, By default, the corresponding UCI configuration file is
located at:

* etc/openwrt/config/[PROFILE_NAME]/stubby

Stubby supports DNSSEC, a feature that verifies the authenticity and
integrity of DNS responses. However, depending on hardware capability,
enabling DNSSEC can have a significant performance impact. DNSSEC is
therefore disabled by default to prevent a network meltdown
post-installation.




WHAT THIS APP DOES

For OpenWRT installation, this function performs the following steps:

1. Transfer the UCI configuration file from the local
   `etc/openwrt/config/[PROFILE_NAME]/stubby` to the remote
   `/etc/config/stubby` via SCP.
2. Add the Stubby package.
3. Check that DNS resolution via Stubby is working.
4. Configure dnsmasq to use DoT after package installation.

For OpenWRT removal, this function performs the following steps:

1. Configure dnsmasq not to use DoT and remove its dependency on Stubby.
2. Check that DNS resolution via dnsmasq is working.
3. Remove the Stubby package.
4. Delete the remote `/etc/config/stubby` UCI file.




THE PKI SIGNATURES

You can further enhance security by supplying the list of DNS servers
together with their PKI certificate hashes. While this ensures the
authenticity of the remote servers, the maintainers MUST update the PKI
hashes periodically.

If the maintainers do not have sufficient resources to maintain these PKI
hashes, it is recommended not to implement this feature.




WHAT IS REQUIRED FROM MAINTAINERS

For OpenWRT, the UCI configuration file MUST be kept up to date and
available at:

* etc/openwrt/config/[PROFILE_NAME]/stubby

This configuration file can be constructed from, or referenced via:

* share/openwrt/config/example/stubby
* share/openwrt/config/example/stubby-minimal




USEFUL DEBUGGING COMMANDS

To debug the network connection and DNS resolution, you can use the
following commands:

```
# debug the Internet connection via ICMP
 $ ping 1.1.1.1


# debug DNS resolution directly via Stubby
 $ nslookup openwrt.org 127.0.0.1:5453


# debug DNS resolution via dnsmasq
 $ nslookup openwrt.org 127.0.0.1
```
