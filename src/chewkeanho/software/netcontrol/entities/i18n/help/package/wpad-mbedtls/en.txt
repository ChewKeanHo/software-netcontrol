FULL WPAD-MBEDTLS PACKAGE

WPAD-MBEDTLS drives and handles wireless operations on a given node device.
By default, OpenWRT ships a trimmed-down basic version to optimize for
size and demand. However, the basic version lacks various important
components, including but not limited to:

1. Enterprise Wireless Encryption
2. 802.11s Mesh Networking

Therefore, if any of the above features is required, the full WPAD-MBEDTLS
package is needed.

Note that installing or removing this package will trigger an update of the
'etc/openwrt/config/[PROFILE_NAME]/wireless' configuration file. Therefore,
you MUST update the configuration to the intended version before running
the installation or removal command.

WHAT THIS APP DOES

In OpenWRT, this function first updates the '/etc/config/wireless' UCI
file from the local 'etc/openwrt/config/[PROFILE_NAME]/wireless' via
classic SCP file transfer.

It only adds or removes the 'WPAD-MBEDTLS' package and its
'WPAD-BASIC-MBEDTLS' package counterpart.

Lastly, it restarts the 'wpad' service as a safety measure.




WHAT IS REQUIRED FROM MAINTAINERS

In OpenWRT, the UCI configuration file MUST be updated and available at:
	${CHEWKEANHO_DIRECTORY_PROJECT}/etc/openwrt/config/wireless

This configuration file can be constructed or referenced via:
	* 'share/openwrt/config/example/wireless'
	* 'share/openwrt/config/example/wireless-minimal-mesh'
	* 'share/openwrt/config/example/wireless-minimal-repeater'
	* 'share/openwrt/config/example/wireless-minimal-leaf'
	* 'share/openwrt/config/example/wireless-sample-ap-consumer'
	* 'share/openwrt/config/example/wireless-sample-ap-enterprise'
	* 'share/openwrt/config/example/wireless-sample-mesh'
	* 'share/openwrt/config/example/wireless-sample-radio-*'
	* 'share/openwrt/config/example/wireless-sample-wifiwan-consumer'
	* 'share/openwrt/config/example/wireless-sample-wifiwan-enterprise'




USEFUL DEBUGGING COMMANDS

To debug wireless features, you can use the following commands:

```
# debug the Internet connection via ICMP
$ ping 1.1.1.1


# debug DNS resolution
$ nslookup openwrt.org


# list all wireless devices' capabilities for this node
$ iw list


# list all wireless devices' supported radio modes
$ iw list | grep -A9 'Supported interface modes'


# get the local regulatory compliance settings
$ iw reg get
```
