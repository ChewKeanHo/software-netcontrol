$ chewkeanho-netcontrol bootstrap [PROFILE_NAME] [REMOTE_IP]
_________________________________________________________________________

BOOTSTRAP COMMAND

This command configures the remote network device ([REMOTE_IP]) to load the
bootstrap configurations from the 'etc/[TECH]/config/[PROFILE_NAME]'
directory into its runtime configuration directory. This effectively
transforms a vanilla device into the specified network router.

The bootstrap configurations **MUST** be pre-configured in such a way that
the device can access the Internet without any dependencies (e.g. a missing
Stubby package). These additional configurations can be made after the
bootstrap is completed, via various supported commands.

The focus here is to restore a vanilla network device back to a usable
network node as quickly as possible without manual effort.

Due to the fact that '${NETCONTROL_DIRECTORY_PROJECT}/etc' contains
sensitive information (e.g. DUID, Wi-Fi passwords, network mapping), one
**MUST**:

1. store all the files safely inside a secret vault for long-term storage at
   rest. Refer: '$ chewkeanho-netcontrol help lock' for help.
