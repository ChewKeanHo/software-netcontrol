$ chewkeanho-netcontrol remove [PACKAGE] [PROFILE_NAME] [REMOTE_IP]
_________________________________________________________________________

REMOVE PACKAGE COMMAND

This command configures the remote network device (`[REMOTE_IP]`) to remove
a particular package (`[PACKAGE]`) from its runtime system using
`[PROFILE_NAME]` configurations.

Depending on the package, NetControl will also configure the network device
to match its supported runtime features. Hence, supported packages are
limited even though the target device offers more packages.

For the list of packages, please look into:

	$ chewkeanho-netcontrol help package

Then, use the following command to learn more about that specific package:

	$ chewkeanho-netcontrol help package [PACKAGE]
